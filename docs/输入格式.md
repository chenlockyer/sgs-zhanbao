# 支持的转写稿格式

`ingest.py` 自动识别，**不用指定**。识别不了的行会被拼到上一段（腾讯会议偶尔断行）。

## 1. 腾讯会议逐字稿（主力）

```
解说甲 共享音频(00:19:09): 好像又有点显示的 bug 在手上……
解说甲 共享音频(00:19:38): 刘备手里现在是只有一张闪……
```

格式：`<发言人> [共享音频|共享屏幕|共享视频]<(HH:MM:SS)>: <内容>`
括号支持半角 `()` 和全角 `（）`，冒号支持 `:` 和 `：`。

## 2. 方括号时间戳（本地 ASR / 流式转写产物）

```
[00:19:09] 好像又有点显示的 bug 在手上……
[00:19:38] 刘备手里现在是只有一张闪……
```

时间戳支持 `HH:MM:SS` 和 `MM:SS`（后者会归一化成前者）。

## 3. 纯文本

```
欢迎来到今天的比赛。
刘焉反叫四分，摸到丈八蛇矛。
```

一行一句，时间戳留空。这种情况下校对只能做「全片段替换」，
不能定位到某一行——所以**有条件还是带时间戳**。

## 编码

UTF-8 / UTF-8-BOM 都行，读的时候会 `errors="replace"`，
所以从微信 / 浏览器另存为的稿子一般不会炸。

## 输出格式

校正稿 `<stem>.corrected.txt` **跟着输入格式走**：

| 输入 | 输出 |
|---|---|
| 腾讯会议 | 原样保留行前缀（`解说甲 共享音频(00:19:09): `），格式与导出完全一致 |
| 方括号 | `[HH:MM:SS] 内容` |
| 纯文本 | 一行一句 |

这样校正稿还能拿回原工具里继续用，不是只能单向消费。

## 日期推断

从文件名抠：`20261105192559-xxx.txt` → `2026-11-05`。
抠不到就用 `--date 2026-11-05` 显式指定（**推荐**，别赌文件名）。

## 拿不到格式怎么办

`sgs-zhanbao doctor` 会打印解析统计。或者直接：

```python
from sgs_zhanbao.ingest import load_transcript
tr = load_transcript("你的稿子.txt")
print(tr["format"], tr["n_segments"], tr["speakers"], tr["duration"])
```

`n_segments` 是 0 会直接抛 `ValueError` 并指向这份文档。
