# 每日操作手册

一场比赛从开播到出图，实际需要你动的地方只有 3 个动作。

---

## 赛前（约 2 分钟）

### 1. 打开直播间并确认开播

```bash
sgs-zhanbao-live live --room 1327597 --open   # 打开浏览器
sgs-zhanbao-live live --wait                  # 轮询等到开播提示
```

### 2. 腾讯会议：快速会议 + 共享屏幕

1. **快速会议** —— 建一个只有自己的会议
2. 底部 **共享屏幕**
3. 选 **仅电脑声音**（不要共享画面，省带宽也更省资源）
4. **开始共享**

> 这两下不自动化，因为腾讯会议的窗口一旦被遮挡或最小化，像素点击就会点错，
> 无人值守反而更危险。理由见 [自动化边界.md](自动化边界.md)。

### 3. 确认录制与转写

会中底部工具栏：

* 点 **录制** → 开始录制（若已设「自动录制」可跳过）
* 右侧面板确认 **逐字稿** 已开启

设置里一次设好，之后每场自动生效：
`设置 → 录制 → ☑ 同时开启录制转写`、`☑ 自动文字转写`

---

## 赛后（约 1 分钟操作 + 5 分钟等待）

### 4. 导出逐字稿

腾讯会议里打开这场会议的 **转写 → 导出文本**，得到 txt，丢进 `voice2text/`。

### 5. 一条命令出图

```bash
sgs-zhanbao run ^
  --transcript voice2text\20261105192559-xxx.txt ^
  --score "第一场：开机大队 14 : 10 败者食尘" ^
  --date 2026-11-05
```

三步：**文字校对 → 战报提取 → 出图**。

* 步骤 1 校对是独立上下文，只修语音转文字的错字（依据 `glossary.yaml`）
* 步骤 2 提取只读校正稿，提示词里**没有**任何纠错规则
* `--score` 不填就从录音里推断（会在 `meta.score_source` 标 `inferred`）
* 已经校对过、只想换比分重跑：加 `--reuse` 跳过校对

第一次跑建议先试两块，确认错字抓得准：

```bash
sgs-zhanbao run --transcript ... --limit 2
```

### 6. 校对与重出

**先看校对清单，再看 JSON，最后出图**：

```
voice2text\<名>.corrections.json   ← 修正清单（含待确认项）
data\2026-11-05\report.json        ← 战报结构化数据
```

* 修正清单里只有 `high` 置信度的会被真正替换；`medium/low` 只标「待确认」等人判断
* **修正清单不进战报正文**，只在 `corrections.json` 留档
* `meta.notes` 是提取模型标记的存疑点
* 改完 JSON 直接重渲染，**不用再调 API**：

```bash
sgs-zhanbao render --data data\2026-11-05\report.json
```

发现漏校/误校，只重跑校对，不用重新写战报：

```bash
sgs-zhanbao proofread --transcript voice2text\你的文件.txt
```

## 常见问题

**Q：比分写错了**
改 `report.json` 里 `matches`，然后 `render`；或下次跑时用 `--score` 明确指定。

**Q：漏校了 / 某个武将名还是错的**
先补 `data/glossary.yaml`（正确写法加到对应条目，错误形态加到误写列表），
然后只重跑 `proofread`，再 `render`。不用改提示词。

**Q：校对把不该改的玩梗改了**
在 `data/prompts/proofread.md` 的「绝对不要改」里补上具体词；
或把它写进 `glossary.yaml` 的 `memes`（会随术语表一起喂给校对模型）。

**Q：战报里出现了看不懂的词**
那是转写稿的同音误听。提示词铁律要求「看不懂的不写」，
但模型偶尔会漏——把它加进 `glossary.yaml` 的误写列表，重跑校对即可。

**Q：想换版式 / 配色 / 素材**
见 [版式与素材.md](版式与素材.md)。

**Q：出图报「素材接缝对不齐」**
说明你的素材没满足三条约束（928 宽、首末行逐像素对齐、mid 列内恒定）。
用 `build_art.py` 重建，它会打印校验值。

**Q：`doctor` 说找不到字体**
不致命，只是观感变差。装一个楷体，或 `--font D:\fonts\mykai.ttf` 指过去。

**Q：想完全离线跑**
见 [本地转写.md](本地转写.md)。

**Q：DeepSeek 挂了 / 想换模型**
`SGS_LLM_BASE_URL` + `SGS_LLM_MODEL` 指向任何兼容 OpenAI 协议的网关即可。

**Q：怎么控制 token 花费**
校对和提取都是**逐块调用**，块数 ≈ 字数 / 1800。
短稿（<6000 字）会自动跳过分块摘要。试跑用 `--limit 2`。
`report.json` 的 `meta.usage` 记了本次实际用量。

## 成品规格（默认）

| 项 | 规格 |
|---|---|
| 记者署名 | `SGS_REPORTER`，默认「战报记者：王战答疑团-江南」，44px 牌面居中 |
| 字体 | 楷体，按用字子集内嵌；正文 32px 加粗、行距 1.15、字距 -0.045em |
| 标题 | `赛事速递 \| M.D SGL主播赛战报`，48px 不缩 |
| 正文篇幅 | 焦点局 2 条 / 名场面 1 条 / 看点 5 行，字数不限 |
| 底部 | 看点总结 + 明日预告 + 恭喜，30% 白柔边压在尾图上 |
| 成品尺寸 | 1856px 宽（2x），高度随正文自适应 |
