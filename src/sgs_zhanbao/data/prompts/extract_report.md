# 铁律

1. **比分以我提供的「赛果信息」为准**。若我没提供，才从录音里推断，并在 `meta.score_source` 写 `"inferred"`。
2. 把解说的判断当成战报的结论陈述，不需要说是解说的观点。
3. `title` 固定为「赛事速递 | M.D SGLxx赛战报」，**M.D 用我给的日期**（如 2026-11-06 → `11.6`，xx是赛事类型，例如主播赛、公会赛等）
4. **看不懂的内容一律不写**。转写稿是语音识别产物，武将名、技能名、选手名、环节名、队名都可能被听成同音怪词。凡是：
   - 你无法确认它对应真实存在的武将/技能/队伍（写出来读者会问「这是什么东东」）；
   - 或明显是生造词、拼接词（如把环节名和武将名粘在一起）；
   
   就**整段略去**，或改用不带专有名词的平实描述（例如只写「一回合连开四次伤害」而不写技能名）。宁可少写一个细节，也不要写出看不懂的东西；存疑的专有名词写进 `meta.notes` 供人工核对，正文不要出现。

# 赛制规则（参考资料）：
叫分环节
1 叫分环节流程
进入叫分环节后，系统会给每名选手的选将框中推送4名武将，选手根据推送的武将进行叫分。叫分的顺序与选手座次一致，比如“先叫位”为一号位的选手，下一个叫分的则是二号位选手；下一个叫分的则是三号位的选手，依次类推。
2 叫分规则
1）选手叫分的倍数有“不叫”、“一倍”、“二倍”、“三倍”、“四倍”，单场对局的倍数与该局选手叫的最高分相等，最低为“一倍”，最高为“四倍”。（四名选手均“不叫”的情况下，以一号位成为地主结算，当局倍数为“一倍”）
2）先叫位的叫分倍数最低为“不叫”，最高为“三倍”。
3）每名选手叫的分数需比上一位的选手高。
4）除“先叫位”选手外，只有在对方选手的叫分高于己方选手的叫分的情况下才能继续叫分。
5）只有在对方选手叫了“三倍”的情况下，己方选手才能叫“四倍”。
6）四位选手均叫分（若其中一名选手叫到“四倍”则直接成为地主）以后，最终叫分倍数最高者成为地主，该队另一名选手暂时不上场，而另一队的两名选手以二号位农民、三号位农民出阵。
3 选将环节
叫分环节结束后，进入双方选将环节，地主的将框中除最初拥有的四个武将外，系统会随机从队友的将框中选择2名武将加入到地主的选将框中，每名选手一局比赛可使用2张换将卡，最终在自己的将框中选择心仪的武将进入正式对局。
4 正式对局
对局开始后，每名选手会拥有四张起始手牌，选手可使用手气卡更换起始手牌，每位选手该小局比赛中手气卡使用次数上限为3次。地主除武将本身技能外，额外拥有“飞扬”“跋扈”以及“强易”技能；农民额外拥有“共苦”技能。
